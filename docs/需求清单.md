# 开心消消乐 · 需求清单

> 本文件是开发项目的「锚点」。每次动手写代码前、每次和 Agent 描述需求时，都以这份清单为准。
> 状态规则：功能条目用 `[ ]`（未做）/ `[x]`（已完成）。每完成一条，来这里勾选。

## 1. 一句话定位（范围锁定）

> **做一个 8×8 棋盘、四种颜色方块、三连消除并下落补位、带计分的消消乐。**

> 说明：这句话是"北极星"。任何偏离它的需求，先问一句"没有它还算消消乐吗？"，再决定要不要加。

---

## 2. 功能清单

### ✅ 必做（MVP）—— 不做就无法叫消消乐

| # | 功能 | 需求说明 | 状态 |
| --- | ------ | ---------- | ------ |
| F1 | 棋盘网格 | 8×8 网格，四色方块正常显示 | [x] |
| F2 | 交换 | 玩家把相邻两块交换位置 | [x] |
| F3 | 三连消除 | 横/竖三块同色相邻 → 同时消失 | [x] |
| F4 | 下落补位 | 消除后上方方块下落，顶部生成新方块 | [x] |
| F5 | 计分 | 每次消除增加分数 | [x] |

### ❌ 先不做（忍住列表）—— 防需求蔓延

- 特殊道具（炸弹、彩虹糖、加步数）
- 关卡系统 / 步数限制 / 通关条件
- 联网 / 排行榜 / 内购 / 多语言 / 成就 / 新手引导
- 音效 / 粒子特效（M7 只做方块运动与点击反馈，不做这些）

> 这条列表和"必做"同样重要。它保护你的学习主线不被打断。

---

## 3. 验收标准（本清单的灵魂，逐步填满）

> 每个功能至少配一条"怎么样算做完了"。**留白处是我们接下来要一起讨论填满的部分。**

### F1 · 棋盘网格

- [x] 8×8 网格；方块尺寸 **64×64**
- [x] 四色 **纯色**（预留将来替换成图片）

### F2 · 交换

- [x] 点击和拖动都支持；**MVP 先只做点击**
- [x] 相邻交换支持 **上下 / 左右**（不支持对角）
- [x] 交互：**点击第一块 → 高亮 → 点击相邻第二块 → 交换 → 取消高亮**
- [x] 点击空白 / 不相邻 → 重置高亮，不交换

### F3 · 三连消除

- [x] **只做三连**（四连 / 五连 MVP 不做）
- [x] **只算横、竖**（45° 斜不算，避免四色棋盘连锁把整盘洗掉）
- [x] 同一时刻多处三连 **同时消除**

### F4 · 下落补位

- [x] **一次落到底**（先做瞬时下落，动画放最后）
- [x] **连锁**：下落完成后若又构成三连，自动再消，直到棋盘稳定
- [x] 连锁带保险丝上限（防极端无穷循环）；正常玩法以“扫不到三连”为准停

### F5 · 计分

- [x] **每消 1 个方块 +10 分**（连锁不额外倍率）
- [x] 分数显示在**棋盘上方居中**

### M7 · 打磨（规则已完成，只改「看起来怎样」）

> 核心逻辑瞬时结算已经能玩。M7 是在数据和画面之间加一段时间，并在这段时间里锁住点击。
> **一次只做一小节。** M7.3 已完成；M7.4 写在这里占位，先别写代码。

#### M7.1 · 锁输入（当前这一步）

- [x] 棋盘有「忙碌」状态：结算进行中时，点击格子**完全无效**（不换选中、不交换）
- [x] 结算结束（棋盘稳定）后，点击恢复正常
- [x] 开局自动消掉漏网三连时，玩家同样点不动（和游戏中同一套锁）

> 说明：这一步本身几乎看不出动画。它是后面滑动/消除/下落的地基——没有锁，动画没播完玩家再点，状态机会乱。

#### M7.2 · 交换滑动（当前已完成）

- [x] 相邻两块滑向对方位置，而不是瞬间换色
- [x] 滑完再扫描三连
- [x] 不成三连则滑回原位（回弹）

#### M7.3 · 消除反馈（当前已完成）

- [x] 要消的格子先缩小或淡出，再变成空洞
- [x] 分数在消除发生时更新（不要提前、也不要拖到下落之后）

#### M7.4 · 下落补位动画（先不做，最难）

- [ ] 存活方块沿列真正向下移动，而不是格子原地换色
- [ ] 顶部新块从棋盘上方掉入
- [ ] 连锁必须「一轮动画播完再播下一轮」，画面不能叠在一起
