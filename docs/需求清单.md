# 开心消消乐 · 需求清单

> 本文件是开发项目的「锚点」。每次动手写代码前、每次和 Agent 描述需求时，都以这份清单为准。
> 状态规则：功能条目用 `[ ]`（未做）/ `[x]`（已完成）。每完成一条，来这里勾选。

## 1. 一句话定位（范围锁定）

### 第一阶段（已完成）

> **做一个 8×8 棋盘、四种颜色方块、三连消除并下落补位、带计分的消消乐。**

规则、连锁、交换/消除/下落动画都已经齐了。这一句话不再扩展。

### 第二阶段（当前主线）

> **把沙盒变成一局能结束的游戏：有剩余步数、步数用完结算、随时可以重新开始。**

> 说明：任何偏离它的需求，先问一句「没有它还算一局游戏吗？」，再决定要不要加。  
> 图片换肤、拆脚本、道具、关卡目标，都不是这一阶段。

## 3. 验收标准（本清单的灵魂，逐步填满）

> 每个功能至少配一条「怎么样算做完了」。**一次只做一小节。**

### F1 · 棋盘网格

- [x] 8×8 网格；方块尺寸 **64×64**
- [x] 四色 **纯色**（预留将来替换成图片）

### F2 · 交换

- [x] 点击和拖动都支持；**MVP 先只做点击**
- [x] 相邻交换支持 **上下 / 左右**（不支持对角）
- [x] 交互：**点击第一块 → 高亮 → 点击相邻第二块 → 交换 → 取消高亮**
- [x] 点击空白 / 不相邻 → 重置高亮，不交换

### F3 · 三连消除

- [x] **只做三连**（四连 / 五连 MVP 不做）
- [x] **只算横、竖**（45° 斜不算，避免四色棋盘连锁把整盘洗掉）
- [x] 同一时刻多处三连 **同时消除**

### F4 · 下落补位

- [x] **一次落到底**（先做瞬时下落，动画放最后）
- [x] **连锁**：下落完成后若又构成三连，自动再消，直到棋盘稳定
- [x] 连锁带保险丝上限（防极端无穷循环）；正常玩法以“扫不到三连”为准停

### F5 · 计分

- [x] **每消 1 个方块 +10 分**（连锁不额外倍率）
- [x] 分数显示在**棋盘上方居中**

### M7 · 打磨（第一阶段，已完成）

> 核心逻辑瞬时结算已经能玩。M7 是在数据和画面之间加一段时间，并在这段时间里锁住点击。

#### M7.1 · 锁输入

- [x] 棋盘有「忙碌」状态：结算进行中时，点击格子**完全无效**（不换选中、不交换）
- [x] 结算结束（棋盘稳定）后，点击恢复正常
- [x] 开局自动消掉漏网三连时，玩家同样点不动（和游戏中同一套锁）

#### M7.2 · 交换滑动

- [x] 相邻两块滑向对方位置，而不是瞬间换色
- [x] 滑完再扫描三连
- [x] 不成三连则滑回原位（回弹）

#### M7.3 · 消除反馈

- [x] 要消的格子先缩小或淡出，再变成空洞
- [x] 分数在消除发生时更新（不要提前、也不要拖到下落之后）

#### M7.4 · 下落补位动画

- [x] 存活方块沿列真正向下移动，而不是格子原地换色
- [x] 顶部新块从棋盘上方掉入
- [x] 连锁必须「一轮动画播完再播下一轮」，画面不能叠在一起

### M8 · 游戏循环（第二阶段，当前主线）

> 现在能一直点，没有结束。M8 要学的是：一局有开头、有过程、有结尾。  
> 会碰到 **按钮、信号、简单 UI**，尽量和棋盘规则分开想：棋盘负责消，UI 负责「这一局还剩几步、能不能再点」。  
> **一次只做一小节。** M8.2 已完成；M8.3 先别写代码。

#### M8.1 · 重新开始（当前已完成）

- [x] 棋盘附近有一个「重新开始」按钮（文案清楚即可，不追求好看）
- [x] 按下后：生成一盘新棋盘（开局仍不能自带三连）、分数归零、选中取消
- [x] 结算 / 动画进行中按按钮：等当前动画结束再重开，或直接打断后重开——两种里选一种，做的时候写进注释；推荐 **直接打断并重开**（玩家按了就立刻生效）
- [x] 重开后可以立刻点击下棋，和第一次进游戏一样

#### M8.2 · 剩余步数（当前已完成）

- [x] 开局有固定步数（常量，例如 **20**），显示在分数附近
- [x] **只有成功交换（成三连）才扣 1 步**；不成三连回弹不扣
- [x] 连锁再消不算额外步数（一次成功交换只扣 1 步）
- [x] 步数随交换立刻更新，不要等整轮连锁播完才减

#### M8.3 · 一局结束（先不做）

- [ ] 步数减到 0 后，等**这一次交换的连锁全部播完**，再锁定棋盘
- [ ] 锁定后：点击格子无效（可复用 `_busy` 或单独的「已结束」状态）
- [ ] 屏幕上能看出「本局结束」，并显示本局分数
- [ ] 「重新开始」在结束后仍然可用，按了就开新局
