# 开心消消乐 · 需求清单

> 本文件是开发项目的「锚点」。每次动手写代码前、每次和 Agent 描述需求时，都以这份清单为准。
> 状态规则：功能条目用 `[ ]`（未做）/ `[x]`（已完成）。每完成一条，来这里勾选。

## 1. 一句话定位（范围锁定）

> **做一个 8×8 棋盘、四种颜色方块、三连消除并下落补位、带计分的消消乐。**

> 说明：这句话是"北极星"。任何偏离它的需求，先问一句"没有它还算消消乐吗？"，再决定要不要加。

---

## 2. 功能清单

### ✅ 必做（MVP）—— 不做就无法叫消消乐

| # | 功能 | 需求说明 | 状态 |
|---|------|----------|------|
| F1 | 棋盘网格 | 8×8 网格，四色方块正常显示 | [x] |
| F2 | 交换 | 玩家把相邻两块交换位置 | [x] |
| F3 | 三连消除 | 横/竖三块同色相邻 → 同时消失 | [ ] |
| F4 | 下落补位 | 消除后上方方块下落，顶部生成新方块 | [ ] |
| F5 | 计分 | 每次消除增加分数 | [ ] |

### ❌ 先不做（忍住列表）—— 防需求蔓延

- 特殊道具（炸弹、彩虹糖、加步数）
- 关卡系统 / 步数限制 / 通关条件
- 交换后无消除自动回弹动画
- 联网 / 排行榜 / 内购 / 多语言 / 成就 / 新手引导

> 这条列表和"必做"同样重要。它保护你的学习主线不被打断。

---

## 3. 验收标准（本清单的灵魂，逐步填满）

> 每个功能至少配一条"怎么样算做完了"。**留白处是我们接下来要一起讨论填满的部分。**

### F1 · 棋盘网格
- [x] 8×8 网格；方块尺寸 **64×64**
- [x] 四色 **纯色**（预留将来替换成图片）

### F2 · 交换
- [x] 点击和拖动都支持；**MVP 先只做点击**
- [x] 相邻交换支持 **上下 / 左右**（不支持对角）
- [x] 交互：**点击第一块 → 高亮 → 点击相邻第二块 → 交换 → 取消高亮**
- [x] 点击空白 / 不相邻 → 重置高亮，不交换

### F3 · 三连消除
- [x] **只做三连**（四连 / 五连 MVP 不做）
- [x] **横、竖、45° 斜** 都算
- [x] 同一时刻多处三连 **同时消除**

### F4 · 下落补位
- [x] **一次落到底**（先做瞬时下落，动画放最后）
- [x] **连锁**：下落完成后若又构成三连，自动再消（放最后一个里程碑）
- 待补：
  - 连锁消除会无限持续吗？（需要上限，后补）

### F5 · 计分
- [x] **每消 1 个方块 +10 分**（连锁不额外倍率）
- [x] 分数显示在**棋盘上方居中**
