## 1. 我是谁 / 我的情况

- **纯初学者**：以前完全没接触过代码，也没做过游戏。
- **学习目标**：通过做这个消消乐，学 **Godot（4.x）** 和 **游戏开发的基本流程**。
- **节奏**：**不着急**，利用**业余时间**，一次学一点，稳扎稳打。
- **协作方式**：**和 Agent 一步步边做边学**。我希望每个改动都配上能看懂的教学注释，Agent 要像"师傅带徒弟"一样解释清楚，而不是直接替我写完代码。

---

## 2. 这个项目是什么

- 一个 **8×8 棋盘、四种颜色方块、三连消除并下落补位、带计分** 的消消乐。
- 技术栈：**Godot 4**（GDScript），纯 2D，目前用 `ColorRect` 纯色方块占位。
- 详细需求见 [docs/需求清单.md](docs/需求清单.md)。那是项目的"锚点"，改代码前先看它。

---

## 3. 现在学到哪了

### 已完成

- **M1**：显示 8×8 彩色棋盘（数据与显示分离：`board` 数据层 + `_tiles` 显示层）
- **M2**：点击交换相邻两块（完整的交互状态机：选中 → 高亮 → 点相邻 → 交换）
- **M3**：三连消除（只算横 / 竖，同一时刻多处三连同时消）
- **M4**：下落补位（消除后逐列压实，方块落到底、顶部补新方块）
- **M5**：计分（每消一格 +10，分数显示在棋盘上方居中）
- **M6**：连锁（消除→下落→再消除，直到棋盘稳定；开局逐格生成，避免自带三连）
- 功能清单 F1–F5 已完成，连锁验收已勾选
- **M7.1**：结算期间锁输入（忙碌时点击无效）
- **M7.2**：交换滑动（有三连则坐下并结算，不成三连则回弹）
- **M7.3**：消除反馈（缩小 + 淡出后再变成空洞，分数跟这次消除一起跳）
- **M7.4**：下落与补块动画（存活块下移，新块从顶上掉入；连锁一轮播完再播下一轮）

## 4. 给 Agent 的协作约定

- **教，而不是代做**：把每一步的原理讲清楚，多用中文注释，代码里"数据层 / 显示层 / 交互状态机"的思想要持续强化。
- **小步走**：一次做一个里程碑，做完让学习者自己跑起来看效果，先确认、再往下。
- **不要贪多**：忍住列表里（道具、关卡、动画等）先不做，保护学习主线。
- **进度要回写**：每完成一条功能或里程碑，更新 `docs/需求清单.md` 并提交。
- **提交清晰**：commit message 写清楚"这一版学会了什么 / 完成了什么"。提交身份：`jop <jop@ubuntu26.04>`（git 自动生成的默认值）。
